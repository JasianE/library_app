# Library App

A browser-based library management app built in **2021** as part of **The Odin Project** curriculum.

## Overview

Live link: https://newlibraryapp.web.app

This project was created to practice working with JavaScript objects, arrays, and DOM manipulation by building a small application to manage a collection of books.

Users can add books, remove them, and track their read status through a simple and interactive UI.

## Features

- Add books with title, author, and page count  
- Toggle read / not read status  
- Remove books from the library  
- Dynamic UI updates without page reloads  
- Card-based layout for displaying books  

## Tech Stack

- HTML  
- CSS (Vanilla)  
- JavaScript (ES6)  

## What I Learned

- Working with objects and constructors/classes  
- Managing collections of data (arrays of objects)  
- Updating the DOM dynamically based on state  
- Handling user input with forms and events  
- Structuring small front-end applications  

## Challenges

- Keeping the UI in sync with application data  
- Designing a clean structure for storing book objects  
- Handling user interactions reliably (add/remove/toggle)  

## Development Notes

This was one of my early projects focused on building a complete, interactive application. The emphasis was on understanding core JavaScript concepts rather than scalability or advanced architecture.

## Reflection

This project helped solidify the connection between data and UI in front-end development. It was an important step toward building more structured and interactive applications.
